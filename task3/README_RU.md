# Задание 3: НОК через HTTP на Python

По сообщению в Discord срок — **18.10.2026**. На 19.10.2026 указанная дата уже прошла; возможность поздней сдачи нужно уточнить у преподавателя.

## Что готово

`app.py` принимает `GET` по пути из регистрационного email. Параметры `x` и `y` должны содержать неотрицательные целые числа, записанные десятичными цифрами `0–9`. Ответ — НОК в виде цифр или ровно `NaN` при неверных данных. Тип ответа: `text/plain; charset=utf-8`; JSON, HTML, кавычек и перевода строки в теле нет.

У каждого символа email, кроме английских букв и цифр, замена — один `_`. Например, **вымышленный** `Student.Name+demo@example.com` даёт `/Student_Name_demo_example_com`. Регистр английских букв сохраняется. Подставь email, с которым зарегистрирован на курсе.

Внешние библиотеки не нужны. Код использует стандартную библиотеку Python 3.12.

## Запуск в PowerShell

Открой терминал в папке `task3` и выполни:

```powershell
$env:REGISTRATION_EMAIL = 'YOUR_REGISTRATION_EMAIL'
$env:HOST = '127.0.0.1'
$env:PORT = '8080'
python app.py
```

В другом терминале в той же папке подставь тот же email:

```powershell
$registrationEmail = 'YOUR_REGISTRATION_EMAIL'
$route = [regex]::Replace($registrationEmail, '[^A-Za-z0-9]', '_')
curl.exe "http://127.0.0.1:8080/${route}?x=12&y=18"
```

Ожидается `36`. Для `x=0&y=18` ожидается `0`, для `x=abc&y=18` — `NaN`. Сервер останавливается `Ctrl+C`.

## Как работает решение

1. `email_path` строит требуемый путь из email.
2. Обработчик `GET` читает `x` и `y` из строки запроса. Отсутствующий, пустой, отрицательный или нецелый параметр даёт `NaN`. Повтор одного параметра также считается неверным запросом.
3. Если хотя бы одно корректное число равно нулю, результат равен `0`, в том числе для пары `0, 0`.
4. Для остальных чисел используется формула `НОК(x, y) = (x // НОД(x, y)) * y`. НОД вычисляет `math.gcd`. Деление целочисленное, округления через `float` нет.
5. Ответ записывается непосредственно в тело HTTP. Python поддерживает большие целые, поэтому результат не ограничен точностью JavaScript Number.

Пробелы, знак `+`, экспоненциальная запись, дроби и цифры других алфавитов намеренно не принимаются: входной формат — десятичные цифры `0–9`. Посторонние параметры игнорируются; они не меняют `x` и `y`.

## Публикация

Публичного адреса в этом комплекте пока нет. Для сдачи нужен доступный проверяющей системе HTTPS-адрес и регистрационный email. Локальный адрес `127.0.0.1` для сдачи не подходит.

В комплекте есть `Dockerfile`. Если Docker установлен, образ можно собрать и запустить локально:

```powershell
docker build -t ilearning-task3 .
docker run --rm -p 8080:8080 -e REGISTRATION_EMAIL='YOUR_REGISTRATION_EMAIL' ilearning-task3
```

При размещении на хостинге с поддержкой Docker задай `REGISTRATION_EMAIL`. Приложение слушает `0.0.0.0` и берёт порт из `PORT` (по умолчанию `8080`). HTTPS должен предоставить хостинг. Контейнер запускается без прав root. Docker-образ и внешний хостинг локальными Python-тестами не проверяются.

После размещения повтори проверки `12,18 → 36`, `0,0 → 0` и `abc,18 → NaN` по публичному HTTPS-адресу.

## Строка сдачи

```text
!task3 YOUR_REGISTRATION_EMAIL https://YOUR-HOST/tolegenovmeiirzhan_gmail_com?x={}&y={}
```

Замени `EMAIL` на регистрационный email, `HOST` — на реальный домен, `EMAIL_SANITIZED` — на email с заменами по правилу выше. Две пары фигурных скобок `{}` оставь буквально: туда проверяющая система подставит числа.

Пример только для понимания формата, **не рабочий адрес**:

```text
!task3 student@example.com https://YOUR-HOST/student_example_com?x={}&y={}
```
