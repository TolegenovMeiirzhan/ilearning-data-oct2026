# ДЗ №4 Data — аналитика книжных магазинов

## Реализация части с данными

pipeline.py читает books.yaml, users.csv и orders.parquet для каждой STORE-папки. В исходном архиве пять магазинов; обработаны все пять. Даты разбираются явно и никогда не заменяются сегодняшней датой. Неправильные записи выводятся в карантин с причиной. Деньги рассчитываются через Decimal и агрегируются в целых центах. Заказ округляется после умножения quantity × unit_price × курс, а не по цене одного экземпляра заранее.

Пользователи связываются при совпадении трёх из четырёх известных полей, затем строятся компоненты связности для последовательных изменений одного поля. Пустые поля совпадениями не считаются. Это учебное правило из условия, а не универсальная проверка личности. Магазины между собой не объединяются.

Набор авторов канонизируется: порядок и повторы имён не создают новый набор. Популярность считается по проданным экземплярам quantity. Лучший покупатель определяется по общей сумме всех связанных ID. Dashboard показывает топ-5 дней, график выручки, количество покупателей/наборов авторов и массивы ID.
