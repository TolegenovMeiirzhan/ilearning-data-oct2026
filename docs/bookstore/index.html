Как рассчитаны показатели

Каждый магазин обработан отдельно. Валюта пересчитана по курсу €1 = $1.2. Сумма заказа округляется до центов после умножения цены на количество. Наборы авторов не зависят от порядка имён. Пользователи объединены, когда совпадают три известных поля из четырёх: имя, адрес, телефон, e-mail. Пустые поля не считаются совпадением.

Диапазон графика меняет только график и его итог. Верхние показатели и рейтинг дней охватывают весь период. Фильтр каталога не изменяет показатели продаж. Исходные данные — учебный набор из задания.
