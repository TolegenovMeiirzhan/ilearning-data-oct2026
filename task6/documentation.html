Task 6 / PostgreSQL procedure library

SQL Faker

Contact generation runs entirely inside PostgreSQL. Python passes the locale, seed, batch and batch size, then renders the JSON returned by the database. No contact fields are generated in Python.

Generate a batch

CALL fake.generate_users('en_US', 42, 0, 10, NULL);

The returned p_result field is a JSON array. The second batch is batch = 1. Supported locales are en_US and de_DE.

ArgumentMeaning
p_locale TEXTLookup locale. Each category must exist in fake.words and fake.word_counts.
p_seed BIGINTSigned 64-bit integer. The same seed and locale reproduce the same stream.
p_batch BIGINTZero-based batch index, 0 to 1,000,000,000.
p_batch_size INTEGER1 to 10,000 for direct SQL. The web endpoint limits pages to 100 users.
p_result JSONB, INOUTPass NULL. Receives the generated records.

Reproducibility and positions

The absolute position is batch * batch_size + index_within_batch. A record depends on its locale, seed, position and named random channels. Changing the page size does not change a record at the same absolute position. No session-level random state is shared between requests.

Procedure reference

ProcedureArguments and use
fake.uniform_value(locale, seed, position, channel, INOUT value DOUBLE PRECISION). Returns a deterministic value strictly between 0 and 1. Different channel names provide separate draws for each attribute.
fake.word(locale, category, seed, position, channel, INOUT value TEXT). Chooses an indexed lookup entry. Categories: first, last, title, street, suffix, city, state, eye.
fake.normal_value(locale, seed, position, channel, mean, deviation, INOUT value DOUBLE PRECISION). Uses two uniform channels and the Box-Muller transform. A negative deviation raises an error.
fake.contact(locale, seed, position, INOUT record JSONB). Generates a full name, formatted address, phone, email, coordinates, height, weight and eye colour.
fake.generate_users(locale, seed, batch, batch_size, INOUT result JSONB). Validates arguments, generates records at consecutive absolute positions and returns one JSON array.

Algorithms

Uniform values: MD5 hashes the UTF-8 text made from locale, seed, position and channel. The first 52 bits form an integer x. The procedure returns (x + 0.5) / 2^52. This is a deterministic test-data generator, not a cryptographic key generator.

Normal values: mean + deviation * sqrt(-2 ln(u)) * cos(2 pi v). Height uses mean 172 cm and deviation 10 cm; weight uses mean 75 kg and deviation 12 kg. Stored output is rounded to two decimals.

Sphere sampling: latitude = asin(2u - 1) and longitude = 2 pi v - pi, converted to degrees. Consequently the sine of latitude is uniform; latitude itself is not uniform. Coordinates are independent of the generated mailing address, as the task requests sampling across the full sphere.

Name and address variants: an optional middle name is included with probability 0.30, a title with probability 0.15, and address/phone layouts vary using independent channels. Addresses use locale-specific word sources and real city names; postcode/city pairs are synthetic and are not validated postal destinations.

Lookup data and extension

Each category is stored in one shared table, keyed by locale, category and a dense one-based position. English first/last name combinations alone exceed 600,000; German combinations exceed 800,000. Middle names, addresses and other attributes expand this space. Records have a unique absolute index and synthetic email, but human names need not be unique.

To add a locale, import its category rows into fake.words with positions 1..N, rebuild fake.word_counts, add the locale to the Python input validator and add its address/phone formatting branch in fake.contact. The lookup schema stays unchanged. Formatting new countries requires a deliberate SQL extension.

INSERT INTO fake.word_counts
SELECT locale, category, COUNT(*) FROM fake.words
GROUP BY locale, category
ON CONFLICT (locale, category)
DO UPDATE SET amount = EXCLUDED.amount;

Python usage

with psycopg.connect(database_url) as connection:
    users = connection.execute(
        "CALL fake.generate_users(%s,%s,%s,%s,NULL)",
        ("de_DE", 42, 0, 10),
    ).fetchone()[0]

Benchmark

The included benchmark measures three batches of 1,000 users using a real local PostgreSQL 18 server. Timing includes the database CALL, network transfer over loopback and client JSON decoding. It excludes browser rendering. See verification/task6-benchmark.json for the measured results and statistical sample checks. Throughput depends on the host and batch size.
