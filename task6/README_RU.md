# ДЗ №6 Data — генератор контактов в SQL

## Что реализовано

Python отображает интерфейс и вызывает `CALL fake.generate_users(...)`. Все поля пользователя формируются пятью хранимыми процедурами PostgreSQL. Поддерживаются en_US и de_DE, seed, переход между порциями, возврат к той же порции, вариации ФИО/адреса/телефона, email, координаты на сфере, рост, вес и цвет глаз.

В `lookup_words.csv` находятся внешние словари. Справочники имён и адресных слов взяты из Faker, города — GeoNames. Python используется только для однократного импорта справочников, не для генерации контактов. Воспроизводимость зависит от неизменности справочников и версии алгоритма.

Исправление 28 октября: немецкий справочник использует семь локальных окончаний улиц (например, straße, weg, allee). Импорт сохраняет SHA-256 CSV и атомарно обновляет учебные справочники при смене версии; повторный запуск с тем же файлом не меняет результаты. Проверены миграция существующей базы и воспроизводимость обеих локалей. В ранней видеодемонстрации №6 ещё виден прежний суффикс Street; текущие немецкие адреса исправлены. Английская выборка и её benchmark не изменились.

Пример SQL:

```sql
CALL fake.generate_users('en_US', 42, 0, 10, NULL);
```

`0` — номер первой порции, `10` — размер. На следующей странице номер порции равен `1`. Формула абсолютной позиции: `batch * batch_size + index`. У одного и того же абсолютного индекса запись сохраняется при изменении размера страницы.

## Как сделано

1. `uniform_value` хеширует locale/seed/позицию/канал и получает число между 0 и 1.
2. `word` по этому числу выбирает строку из общего справочника.
3. `normal_value` применяет преобразование Бокса—Мюллера для роста и веса.
4. `contact` соединяет поля и форматирует их по локали. Широта вычисляется через `asin(2u-1)`, поэтому точки равномерны по площади сферы.
5. `generate_users` проверяет аргументы и собирает порцию в JSON.

Это тестовые контакты. Почта использует example.test. Адреса не предназначены для доставки: индекс и город не проверяются как реальная почтовая пара. Геокоординаты распределены по всей сфере независимо от локали — это требование задания.

## Запуск и проверка

Запуск всего приложения описан в корневом `START_HERE_RU.md`. Открой `http://127.0.0.1:8095/#contacts`. Документация процедур: `/task6/docs`.

Проверено на настоящем PostgreSQL: одинаковые аргументы дают одинаковый JSON; другая локаль/seed меняют JSON; соседние порции имеют разные индексы; некорректные параметры отклоняются. На выборке проверены диапазоны координат, среднее/дисперсия синуса широты и распределения роста/веса. Это выборочные статистические проверки, не доказательство идеальной случайности.

Результаты измерений скорости: `../verification/task6-benchmark.json`. Не выдавай локальные цифры за скорость публичного хостинга.
