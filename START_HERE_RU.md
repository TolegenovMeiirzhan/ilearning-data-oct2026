# Начни здесь

## Что находится в комплекте

Это ДЗ курса iLearning по Data: решения №1–3, №3.5, часть с данными №4, №5, №6 и подготовленное XOR-упражнение из practice. Отдельный комплект python-sql-practice содержит 11 учебных задач из нашего плана, включая решения первых трёх задач про заказы.

Во всех папках есть README_RU.md: как сделано, как проверить, что требуется для сдачи и что изучить. Сначала открой STATUS.md: там честно отмечены незавершённые внешние действия.

## Уже запущено на этом компьютере

Если локальный сервер ещё работает, открой http://127.0.0.1:8095/ . Он показывает №3.5, №4, №5 и №6. Это локальный адрес, преподаватель с другого компьютера по нему не зайдёт.

## Самостоятельный запуск после распаковки

Из папки ilearning-data в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm install
npm start
```

Открой http://127.0.0.1:8095/ . npm start запускает отдельную локальную PostgreSQL и Python-сервер. Данные этой учебной БД сохраняются в .local; не отправляй эту папку, пароли и .env-файлы в GitHub. Порт PostgreSQL — 55440, HTTP — 8095. Если они заняты, сначала останови свой прежний запуск; не завершай чужие процессы вслепую. Остановка — Ctrl+C в терминале запуска.

Для №1 нужен Node.js: node task1/lcs.js ABCDEFZ WBCDXYZ → BCD. №2 и №3 используют стандартную библиотеку Python; их инструкции находятся в своих папках. Повторно отправлять уже принятые №1–3 не нужно.

## Публичный запуск

В корне есть Dockerfile и render.yaml с plan: free. Контейнер запускает PostgreSQL только на loopback и восстанавливает справочники при каждом новом старте. Нужны Docker-совместимый хостинг и публичный HTTPS-адрес. Контейнер в этой среде не собирался: Docker отсутствует. Не считай конфигурацию доказательством успешного развёртывания.

В Render: новый Web Service из репозитория → Docker → Free → проверить /health, все страницы и API. Не выбирай платный план без своего решения. Публичный адрес затем вставляется в черновики писем. При публикации исходников не загружай .local, .venv, ключи и служебные файлы.

## Что требуется от тебя после возвращения

1. Прочитать STATUS.md и нужные README.
2. Открыть локальные страницы и воспроизвести команды самостоятельно.
3. Включить публичное редактирование таблицы №5 и проверить её в инкогнито.
4. Завершить AI-доступ для №4, если сдаёшь полное задание, и проверить реальные ответы.
5. Опубликовать Python-приложение и проверить с телефона/другого браузера.
6. Записать настоящие видео демонстрации: горизонтальные, не ниже 1080p, без звука. Готовые видео в этом комплекте отсутствуют.
7. Заполнить публичные ссылки и ФИО в черновиках писем. Письма и сообщения Discord не отправлялись.
